## 产品愿景

Pet Companionship 是一款虚拟宠物伴侣应用，让用户能够：
- 上传宠物照片，生成可互动的 2D 动画宠物
- 宠物可在电脑桌面、手机灵动岛等场景中自由活动
- 记录和收藏与宠物的珍贵回忆
- 与其他宠物爱好者交流互动

## 功能模块

### 用户系统
- 登录 / 注册
- 个人资料管理
- 偏好设置

### 宠物档案
- 上传宠物图片
- 宠物基本信息（名字、品种、年龄、性别）
- 性格标签
- 独特习惯
- 健康摘要（体重、运动量）
- 医疗记录

### 桌面宠物
- 2D 动画宠物渲染
- 动作系统：待机、睡觉、吃饭、左右移动、玩耍
- 桌面端：电脑桌面浮窗
- 移动端：iOS 灵动岛

### 记忆宫殿
- 照片/视频收藏
- 里程碑时间线
- 成就系统

### 社区
- 动态分享
- 用户互动（点赞、评论）
- 活动/话题

### App Store 展示页
- 应用介绍落地页

## UI 设计系统

基于 `UI_Reference/` 目录下的 HTML 设计稿，提取的设计规范：

### 配色
- 主色 (Primary): `#ec3713`
- 浅色背景: `#f8f6f6`
- 深色背景: `#221310`
- 支持 Light/Dark 模式

### 字体
- 主字体: Plus Jakarta Sans
- 字重: 400 / 500 / 600 / 700 / 800

### 组件风格
- 圆角: 默认 0.5rem, lg 1rem, xl 1.5rem, full 9999px
- 卡片: 白色背景 + 细边框 (border-primary/5) + 微阴影
- 按钮: 圆角 + primary 色 + hover 缩放效果
- 图标: Material Symbols Outlined
- 标签: 圆角胶囊 + primary/10 背景 + primary 文字

### CSS 框架
- TailwindCSS (CDN 模式，后续需迁移到构建工具)
