## Bug 报告模板

每个 Bug 报告必须包含以下信息：

```markdown
## Bug Report

### 标题
[简洁描述问题，如：「登录页提交后无响应」]

### 严重级别
[P0/P1/P2/P3]

### 环境
- 浏览器: Chrome 120 / Safari 17 / Firefox 121
- 设备: Desktop / iPhone 15 / Android
- 前端版本: commit hash / branch
- 后端版本: commit hash / branch

### 复现步骤
1. 打开登录页面 `/login`
2. 输入邮箱 `test@example.com`
3. 输入密码 `wrongpassword`
4. 点击「登录」按钮

### 预期行为
显示「邮箱或密码错误」的错误提示

### 实际行为
按钮变为 loading 状态后无任何反馈，页面停留在登录页

### 截图/录屏
[附图或视频链接]

### 日志信息
```
[控制台报错、网络请求截图、后端日志等]
```

### 影响范围
[影响多少用户？哪些功能受影响？有没有临时绕过方案？]

### 可能原因
[如果有线索，写下你的猜测]
```

## 严重级别

| 级别 | 定义 | 修复时限 | 示例 |
|------|------|----------|------|
| **P0 - 阻塞** | 核心功能完全不可用 | 立即修复 | 登录接口 500、数据库连接失败、支付流程崩溃 |
| **P1 - 严重** | 核心功能部分受损 | 24 小时内 | 注册成功但无法验证邮箱、宠物创建偶尔失败 |
| **P2 - 一般** | 非核心功能问题 | 下个迭代 | 头像上传后缩略图模糊、社区排序不正确 |
| **P3 - 轻微** | 视觉或体验问题 | 有空再修 | 某页面间距不一致、文案错别字 |

### 分级原则
- 影响所有用户 → 至少 P1
- 影响核心流程（注册/登录/宠物管理）→ 至少 P1
- 有数据丢失风险 → P0
- 安全漏洞 → P0

## Bug 生命周期

```
New → Confirmed → In Progress → Fixed → Verified → Closed
                                  ↓
                               Reopened (验证未通过)
```

### 状态说明

| 状态 | 谁操作 | 说明 |
|------|--------|------|
| **New** | 任何人 | 发现 Bug，提交报告 |
| **Confirmed** | QA | 确认可复现，标记严重级别 |
| **In Progress** | BE/FE | 开发人员认领并开始修复 |
| **Fixed** | BE/FE | 提交修复代码，标记为已修复 |
| **Verified** | QA | QA 验证修复有效 |
| **Closed** | QA | 验证通过，关闭 Bug |
| **Reopened** | QA | 验证未通过，重新打开 |

## 回归测试

### 什么时候做回归测试
- Bug 修复后必须回归
- 每次发版前全量回归核心路径
- 重大重构后全量回归

### 回归测试清单

#### 核心路径（每次发版必测）
- [ ] 用户注册 → 邮箱验证 → 登录
- [ ] 创建宠物 → 上传照片 → 查看详情
- [ ] 记忆宫殿 → 创建记忆 → 时间线展示
- [ ] 社区 → 发布动态 → 评论 → 点赞
- [ ] 个人中心 → 修改资料 → 退出登录

#### 非核心路径（发版前选测）
- [ ] 忘记密码 → 重置
- [ ] OAuth 登录（Google/Apple）
- [ ] 深色模式切换
- [ ] 中英文切换
- [ ] 移动端适配

### Bug 修复验证步骤
1. 按照原始 Bug 的复现步骤操作
2. 确认问题已修复
3. 检查相关功能是否引入新问题
4. 更新 Bug 状态为 Verified / Reopened

## Bug 列表管理

### Bug 统计指标

| 指标 | 计算方式 | 健康标准 |
|------|----------|----------|
| 未关闭 Bug 数 | New + Confirmed + In Progress | < 20 |
| P0/P1 Bug 数 | 高优先级未关闭 | = 0 |
| Bug 修复周期 | 从 Confirmed 到 Verified | P0 < 1天, P1 < 3天 |
| Bug 回开率 | Reopened / (Fixed + Verified) | < 10% |
