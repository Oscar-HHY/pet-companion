## 基础交互

### 按钮状态
| 状态 | 样式 |
|------|------|
| 默认 | 标准样式 |
| 悬停 | `hover:scale-[1.02]` 或 `hover:bg-primary/20` |
| 点击 | `active:scale-95` |
| 禁用 | `opacity-50 cursor-not-allowed` |
| 加载中 | 替换文字为旋转图标 |

### 点击反馈
- 主按钮: 缩放 + 阴影变化
- 图标按钮: 背景色加深
- 列表项: 轻微缩放或背景色变化
- 链接: 颜色变化

### 悬停效果
- 卡片: 轻微上浮 `hover:-translate-y-0.5 hover:shadow-md`
- 按钮: 缩放 `hover:scale-[1.02]`
- 图标: 背景加深 `hover:bg-primary/20`

## 页面导航

### 导航模式
| 模式 | 适用场景 | 示例 |
|------|----------|------|
| 顶部导航 + 返回 | 详情页 | 宠物档案页 |
| 底部 Tab 导航 | 主页面 | 首页、社区、我的 |
| 侧边抽屉 | 设置/个人信息 | 设置页 |

### 页面切换
- 前进: 从右向左滑入
- 后退: 从左向右滑出
- Tab 切换: 淡入淡出

### 面包屑
- 一级页面: 不需要
- 二级页面: 左上角返回按钮 + 页面标题
- 三级页面: 左上角返回按钮 + 路径提示

## 表单交互

### 输入框
- 获得焦点: 边框变为 primary 色 `focus:border-primary focus:ring-1 focus:ring-primary`
- 输入中: 实时字符计数（如有长度限制）
- 失去焦点: 触发验证

### 表单验证
- 实时验证: 失去焦点时校验
- 错误提示: 输入框下方红色文字 `text-red-500 text-xs mt-1`
- 成功提示: 输入框右侧绿色勾 ✓

### 文件上传
1. 点击上传区域 → 打开文件选择器
2. 选择文件 → 显示上传进度条
3. 上传完成 → 显示预览 + 删除按钮
4. 上传失败 → 显示重试按钮

## 反馈机制

### Toast 提示
- 成功: 顶部绿色横幅，2 秒后自动消失
- 错误: 顶部红色横幅，需手动关闭
- 信息: 顶部蓝色横幅，3 秒后自动消失
- 位置: 页面顶部居中

### Loading 状态
- 页面加载: 全屏骨架屏
- 区域加载: 骨架屏替换内容区域
- 按钮加载: 文字替换为旋转图标 + "Loading..."
- 列表加载更多: 底部加载指示器

### 空状态
- 无数据: 居中图标 + 文字 + 操作按钮
- 搜索无结果: "未找到匹配结果" + 建议

### 确认对话框
- 删除等危险操作必须弹出确认
- 双按钮: 取消（灰色）+ 确认（红色/primary）
- 背景模糊 `backdrop-blur-sm`

## 动效规范

### 时长标准
| 类型 | 时长 | 缓动函数 |
|------|------|----------|
| 微交互（按钮、图标） | 150ms | ease-out |
| 页面切换 | 300ms | ease-in-out |
| 模态框出现 | 200ms | ease-out |
| 模态框消失 | 150ms | ease-in |
| 展开/折叠 | 250ms | ease-in-out |

### TailwindCSS 过渡
```html
<!-- 基础过渡 -->
<div class="transition-all duration-200 ease-out">

<!-- 颜色过渡 -->
<button class="transition-colors duration-150">

<!-- 变换过渡 -->
<div class="transition-transform duration-300 ease-in-out">
```

### 关键动效
| 场景 | 动效 |
|------|------|
| 页面进入 | 从下方淡入上移 `animate-fadeInUp` |
| 卡片出现 | 依次淡入 + 上移（错开 50ms） |
| 弹窗出现 | 缩放 + 淡入 |
| 下拉刷新 | 顶部拉出 + 旋转图标 |
| 宠物动画 | sprite sheet 逐帧播放 |

### CSS 自定义动画
```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}
```

## 手势交互

### 移动端手势
| 手势 | 用途 |
|------|------|
| 左滑 | 列表项操作（删除、编辑） |
| 下拉 | 刷新 |
| 上滑 | 加载更多 |
| 双击 | 点赞（社区动态） |
| 长按 | 弹出操作菜单 |

### 桌面端交互
| 交互 | 用途 |
|------|------|
| 右键 | 上下文菜单 |
| 拖拽 | 排序、上传文件 |
| 双击 | 编辑 |
| 滚轮 | 滚动、缩放 |
