# 页面设计检查清单

每个页面交付前，逐项检查以下内容。

## 1. 风格一致性

- [ ] 使用项目主色 `#ec3713`
- [ ] 字体为 Plus Jakarta Sans
- [ ] 图标来自 Material Symbols Outlined
- [ ] 圆角、阴影、边框符合设计系统
- [ ] 卡片样式与现有页面一致
- [ ] 按钮样式与现有页面一致

## 2. 布局结构

- [ ] 页面有清晰的信息层次
- [ ] 使用统一的网格系统
- [ ] 内容区最大宽度 `max-w-[960px]`
- [ ] 内边距符合规范（移动端 `px-6`，桌面端 `lg:px-10`~`lg:px-40`）
- [ ] 区块间距合理（`mb-8`~`mb-10`）

## 3. 响应式

- [ ] 移动端布局正常（< 768px）
- [ ] 平板端布局正常（768px - 1023px）
- [ ] 桌面端布局正常（≥ 1024px）
- [ ] 文字不溢出容器
- [ ] 图片正确缩放
- [ ] 触控目标 ≥ 44px

## 4. 交互完整性

- [ ] 按钮有 hover/active 状态
- [ ] 输入框有 focus 状态
- [ ] 所有可点击元素有 `cursor-pointer`
- [ ] 加载状态有指示
- [ ] 空状态有提示
- [ ] 错误状态有提示

## 5. Dark Mode

- [ ] 背景色切换正常（`bg-background-light` / `dark:bg-background-dark`）
- [ ] 文字颜色切换正常（`text-slate-900` / `dark:text-slate-100`）
- [ ] 卡片背景切换正常（`bg-white` / `dark:bg-slate-900`）
- [ ] 图标和标签在深色模式下可见

## 6. 可访问性

- [ ] 图片有 alt 或 data-alt 属性
- [ ] 颜色对比度足够（文字与背景）
- [ ] 表单元素有关联的标签
- [ ] 按钮有明确的文字或 aria-label

## 7. 代码质量

- [ ] HTML 结构语义化（header/main/section/nav）
- [ ] class 命名使用 TailwindCSS 工具类
- [ ] 无行内样式（style 属性），除非必要（如背景图）
- [ ] 无冗余嵌套
- [ ] 代码整洁、缩进一致

## 8. 内容

- [ ] 使用合理的占位数据（非 lorem ipsum）
- [ ] 数据格式正确（日期、货币、数字）
- [ ] 中英文混排时间距合理
- [ ] 文案语调一致
