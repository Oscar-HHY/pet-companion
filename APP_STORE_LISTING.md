## Age Rating Questionnaire

Apple shows ~12 questions. Pet Companion answers:

| Question | Answer |
|---|---|
| Cartoon or Fantasy Violence | **None** |
| Realistic Violence | **None** |
| Prolonged Graphic or Sadistic Realistic Violence | **None** |
| Profanity or Crude Humor | **None** |
| Mature/Suggestive Themes | **None** |
| Horror/Fear Themes | **None** |
| Sexual Content or Nudity | **None** |
| Graphic Sexual Content and Nudity | **None** |
| Alcohol, Tobacco, or Drug Use or References | **None** |
| Simulated Gambling | **None** |
| Medical/Treatment Information | **Infrequent/Mild** *(you log pet vaccinations and medical visits, but offer no advice)* |
| Contests | **None** |
| Unrestricted Web Access | **No** |
| Gambling | **No** |

Apple will likely auto-calculate **12+** because:
- You have **User-Generated Content** (community posts, comments, chat messages)
- You have a moderation pipeline (report + block + EULA gate) — required for any non-4+ UGC rating

If Apple's questionnaire has a "User Generated Content" sub-question (rolled out 2024+):
- **"Does your app contain user-generated content?"** → **Yes**
- **"Have you implemented moderation tools (report, block, EULA)?"** → **Yes** (✓ all shipped)

Expected final rating: **12+** *(or 4+ if Apple doesn't flag the chat feature — varies by reviewer)*

## What App Store Connect will NOT ask for at submission time

These come up only later, in different sections:
- **Screenshots** (Step 13) — uploaded under "Pricing & Availability → Version Information → Screenshots" per device size
- **Build** (Step 16–17) — uploaded via Xcode/EAS, then selected here
- **Demo account** (Step 15) — under "App Review Information" right before Submit for Review
- **Privacy Nutrition Labels** (Step 6) — under "App Privacy" — answer key in `APP_STORE_PRIVACY_LABELS.md`
